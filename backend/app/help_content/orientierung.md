## Ziel

Semaporter bündelt die Verwaltung und Ausführung Ihrer Semaphore-Automatisierung. Die verfügbaren Projekte und Aktionen richten sich nach den Freigaben Ihres Kontos.

## Begriffe

| Begriff | Bedeutung |
| --- | --- |
| Tenant | Organisatorische und technische Zuordnung einer Umgebung, einschließlich ihrer Projekt- und Zugriffsregeln. |
| Semaphore-Projekt | Enthält unter anderem Repositories, Inventories, Variablengruppen, Zugangsschlüssel und Task-Templates. |
| Anwendung | Das bereitzustellende Programm. Eine Anwendung kann aus mehreren Containern bestehen. |
| Runtime-Scope | Zusätzliche Laufzeitzuordnung innerhalb eines Tenants; Bestandteil der konfigurierten Secret- und Deployment-Zuordnung. |
| Provider | Freigegebene Datenbankvariante, beispielsweise PostgreSQL oder MariaDB. |
| Dataset | Ein katalogisierter Testdatenbestand für eine unterstützte Kombination. |
| Task | Eine einzelne Ausführung eines Automatisierungsablaufs. |

## Vorgehen

Öffnen Sie **Meine Projekte** und wählen Sie den gewünschten Tenant. Die Projektseite zeigt die freigegebenen Tasks. Die anschließende Ausführung erfolgt über die im Backend konfigurierte Semaphore-Anbindung.

Fehlt ein Projekt oder eine Aktion, nennen Sie der Administration das betroffene Projekt und die benötigte Tätigkeit. Die Mitgliedschaft in einem Team oder die sichtbare Zuständigkeit im Personenprofil ersetzt keine technische Freigabe.
